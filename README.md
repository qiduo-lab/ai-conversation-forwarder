# AI 对话转发器

[English](README.en.md)

像微信的「合并转发」一样：在一个 AI 对话里勾选几条消息，一键复制，粘贴给另一个 AI。

接收方会清楚地知道，这些话来自哪个 AI、哪段对话，分别是谁说的。

```text
【以下转自 ChatGPT 对话《组织合作机制思考》，共 3 条】

【我】
我觉得好的组织不应该依赖每个人都很善良。

【ChatGPT】
好的管理，或许不是让人变得更善良，
而是让人不必以牺牲自己的利益为代价，
才能做出对集体有益的选择。

【我】
那么什么样的制度可以实现这一点？
```

## 为什么做这个

我经常让不同的 AI 独立判断同一个问题：在 ChatGPT 里聊出一个想法，想听听 Claude 怎么看；在 Claude 里得到一个好回答，想拿给 ChatGPT 继续讨论。

每次都要手动复制、整理"谁说了什么"，很麻烦。有些转发工具会顺手帮你总结、改写，可我想要的恰恰是原话。

所以这个工具只做一件事：**把原始对话原样搬过去**。不总结、不改写、不加任何提示语。

## 支持的平台

| 平台 | 网址 |
| --- | --- |
| Claude | claude.ai |
| ChatGPT | chatgpt.com、chat.openai.com |

只能在电脑浏览器（Chrome、Edge 等）的网页版里使用，Claude 和 ChatGPT 的桌面 App、手机 App 都用不了。

## 安装

1. 在浏览器里安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 扩展。
2. 新版 Chrome / Edge 还需要打开一个开关：地址栏输入 `chrome://extensions`（Edge 输入 `edge://extensions`），找到篡改猴，点「详细信息」，打开「允许用户脚本」。如果找不到这个开关，就打开扩展页右上角的「开发者模式」。
3. 安装脚本，两种方式任选一种：
   - 从 Greasy Fork 安装（推荐，可自动更新）：*链接待发布后补充*
   - 从本仓库安装：点开 [ai-conversation-forwarder.user.js](https://github.com/qiduo-lab/ai-conversation-forwarder/raw/main/ai-conversation-forwarder.user.js)，篡改猴会弹出安装页面，点「安装」。
4. 刷新 Claude 或 ChatGPT 的页面。

## 使用

1. 打开一段对话，点页面右上方的「勾选转发」。
2. 点消息本身，或者点左边的小圆圈，就能选中；再点一次取消。按住 Shift 可以连选一段。
3. 点底部的「复制转发」。
4. 到另一个 AI 的对话框里粘贴。

按 Esc，或者点「取消」，可以随时退出。

## 复制的内容

- 自动标明来源平台和对话标题。
- 每条消息前标注【我】或【AI 名称】，顺序和原对话一致。
- 尽量保留换行、段落、列表、代码块、表格和公式。
- 只复制你勾选的消息，消息正文一个字不改。
- 网页上不属于消息正文的东西会去掉：时间、按钮上的字、"已思考 X 秒"这类思考过程摘要、给读屏软件用的隐藏文字。

## 隐私

- 所有处理都在你自己的浏览器里完成。
- 脚本**不联网**，不收集、不上传任何对话内容，也没有任何统计代码。
- 用到的篡改猴权限只有三项：写入剪贴板（`GM_setClipboard`）、添加界面样式（`GM_addStyle`）、在篡改猴菜单里加选项（`GM_registerMenuCommand`）。
- 代码完全公开，没有压缩或混淆，任何人都可以检查。

## 已知限制

- **附件带不过去**：图片、PDF 等附件的内容存在 AI 网站的服务器上，网页里只有一张卡片，所以没法复制。需要的话，请把原文件手动拖进新对话。
- **网站改版可能导致失效**：Claude 和 ChatGPT 的网页会不定期改版。如果出现「没找到消息」，请看下面的「遇到问题」。

## 遇到问题

1. 在出问题的对话页面上，点浏览器右上角的篡改猴图标，选「复制诊断信息（不含对话内容）」。
2. 到本仓库的 [Issues](https://github.com/qiduo-lab/ai-conversation-forwarder/issues) 新建一个问题，把诊断信息粘贴进去，再说一下是哪个平台、出现了什么情况。

诊断信息里只有网页结构、标记名和字数，**不包含任何对话文字**。

## 代码结构

脚本是一个单独的文件，分成两层：

- **平台适配**：每个平台一小段，负责认出哪些是用户消息、哪些是 AI 回复、对话标题是什么、回复里哪部分是正文。
- **公共部分**：勾选界面、底部操作栏、把网页内容转成文字、复制到剪贴板。

以后要支持新的平台（比如 Gemini、DeepSeek），只需要新增一段平台适配，不用改公共部分。欢迎提交。
